# CostHub：流光玻璃全局设计与手账交互

设计依据：2026-09-06 用户提供的首页参考图，以及现有 `liquidLight` 主题。**本文替代 09-05 设计稿中的松绿色、平面纸感方向。**旧验收报告中的技术发现属于当时版本，本轮未复验后端，不更新其通过/阻塞状态。

本轮交付可操作原型与全局实施规格；没有修改正式业务源码、数据库、用户设置或模型连接。继续沿用“设计文档交给 Luna 实施，再验收”的协作方式。

## 2. 方向：冰蓝流光、磨砂玻璃、少量实体物件

参考图的价值在于环境光、白色磨砂表面、深色信息与蓝色主操作形成统一空间。保留现有产品身份，提升材质的分层和交互的连续性。

| Before | After | Why |
| --- | --- | --- |
| 上一设计稿改成松绿色工作空间 | 回到现有冰蓝、银白、深蓝灰 | 尊重用户明确的流光玻璃方向 |
| 玻璃强度由页面各自决定 | 壳层、业务表面、弹层三个透明度层级 | 内容层次稳定，背景不干扰数字 |
| 3D 只作装饰或所有卡片一起倾斜 | 手账封面、纸边、书脊、资料夹承担空间感 | 形态与“取用、归档、翻阅”的动作一致 |
| 工作记录是普通信息卡片 | 册架、双页阅读、便签与紧凑列表共用记录 | 调阅有物感，高频查找仍直接 |
| 翻页与选册都用同一种淡入 | 选册横向归位、封面绕书脊打开、正文轻翻 | 动作方向帮助理解对象关系 |
| 图中有完成率、月环比和累计降本 | 仅显示当前数据能支持的指标 | 参考图不能替代真实指标定义 |

不做七彩霓虹、持续光带、自动旋转模型、鼠标追光、全屏粒子。首页图表、成本表格、键盘输入不跟着漂浮。禁止把微小文字调得更浅来制造“高级感”。

### 颜色与表面

直接延续 `src/theme/themes.ts` 中 liquidLight 的语义值，正式工程使用现有变量，不另建平行主题框架：

| 角色 | 起点 |
| --- | --- |
| 环境底色 | `#EAF1FA`，局部使用低强度冰蓝静态光晕 |
| 主操作 | `#2F6FED`，仅按钮有轻微上浅下深高光 |
| 主文字 | `#172033` 到 `#182540` |
| 次文字 | `#5F6C80` 到 `#66758F` |
| 玻璃表面 | 白色约 0.73–0.90 不透明度；数据密集区取较高值 |
| 边界 | `rgba(102,137,182,.20)` 配合细白色内高光 |
| 状态 | 绿、琥珀、红只表达状态；始终配文字 |

玻璃模糊集中在侧栏及必要弹层，静态卡片用透明底、边线、阴影即可取得层次。不要每个表格单元格独立 blur，更不能动画 blur 半径。

字体沿用本地 UI 字体。主标题约 26–28px，正文/业务数据约 13px，说明 11–12px，关键金额 32–42px。手账正文仍清楚易读，衬线只用于阅读标题。金额两位小数、右对齐、等宽数字，禁止滚动计数动画。

## 3. 全局页面怎么落地

| 页面/区域 | 设计与操作 |
| --- | --- |
| App 壳层 | 保留今日工作台、项目、情报、资料库、工作手账五项；白色磨砂侧栏，统一蓝色选中态，固定搜索与 AI 入口。窄窗口压缩为有可访问名称的图标栏 |
| 今日工作台 | 左侧一个当前关注项目，中间成本进展，右侧下一步事项；底部成本分布。当前关注显示真实差额，不把未知完成率画成进度 |
| 项目目录 | 最近/关注项目快速进入；完整目录保留搜索、分组、排序、归档。原型使用四个项目示例 |
| 项目工作区 | 项目身份与规格固定；当前标准成本、目标与差额同屏。领域表格与下一步决策并排，报价和版本保持独立入口 |
| 规格/成本策划 | 套用同一页头、分段表单、固定保存反馈。明确版本、来源与费率入口，保持现有业务名称和字段 |
| BOM/器件/模块 | 平面高密度数据表：稳定列宽、排序、筛选、批量操作、编辑状态、冻结状态。细节从上下文抽屉展开，不把器件行改成 3D 卡片 |
| 供应商/竞品/对比 | 用同一套表格与来源抽屉；保留多供应商口径、可比性条件与未知项。图表统一蓝阶，业务状态色按语义使用 |
| 情报 | 信号列表以结论、证据状态、关联项目排序展示；可筛选待补证据。右侧保留当前分析上下文，AI 建议始终可追溯 |
| 资料库 | 上方少量项目/类型文件夹，下方高效文件表；悬停时纸张轻抬，打开后沿用文件预览与来源关系。数百项目时使用搜索，不铺数百个拟物文件夹 |
| 工作手账 | 册架作调阅入口，双页作阅读，便签作散点浏览，列表作快速定位。四者不形成四套数据 |
| AI 协作 | 沿用现有侧面板与本地/云端状态，统一空间与动画。显示正在使用的项目、来源和草稿状态，不让按钮高光代表“可信” |
| 导入/报告/设置 | 复用现有步骤、原生反馈、失败恢复和控件；切换到统一玻璃令牌。多步骤动作进度必须来自真实执行 |

原型中的“工作备忘”表示未关联项目的记录组；MEMO 是封面视觉缩写，正式业务名称用中文。手账册默认由项目关系分组，时间范围取实际记录；不要为了造型新建目录、实体文件或成本模型。

## 4. 手账：像调阅专辑一样取用一本记录

### 册架

选中册居中，左右册轻微透视后退；封面有细微纹理、浅压边、书脊、侧面纸边和一枚索引标签。配色只用冰蓝、雾白、蓝灰，标签少量麦黄色。封面文字直接来自项目代号、名称、时间范围与记录数。

点击左右册或箭头，将目标册移到中心；再次通过“展开手账”进入阅读。原型是三册循环示例。正式大量项目应提供最近/关注范围和可搜索目录，避免无限转盘成为唯一入口。保留所选项目与阅读位置，返回后继续刚才的位置。

### 展开与阅读

进入时册页轻微抬起，封面沿书脊轴打开；左页目录，右页正文。阅读时停止空间动画，纸面颜色接近中性暖白，不把全局环境改为复古黄。纸边与书脊阴影构成实体感。

页内容依次是日期与类型、标题、正文、下一步与证据。支持目录直达、上一页/下一页、方向键与 Escape。证据在上层抽屉打开，关闭回到原页。读长记录时只滚动阅读区域，不自动翻页。

连续快速点击必须直接到最终页，不排队播放。键盘翻阅直接响应，省去翻转。关闭时短暂淡出回到册架，不播放一遍长动画。

### 便签与编辑

便签展示同一组记录的摘要，轻微倾角、纸角与贴条是材质，不是新的业务状态。最多采用淡黄、冰蓝、温白三类纸面。记录的风险/完成状态仍用明确文字、标签或勾选。

复用 WorkLog 现有字段：记录类型、阶段、日期、项目、标题、正文、影响、下一步、截止时间、重要性、证据、跟进状态。当前原型编辑器仅演示常用字段，正式实施不能删除高级字段、删除操作、项目轨迹与 AI 总结等现有入口。

保存失败保留输入，成功才更新目录、计数与正文。改变关联项目时重新校验原证据关系。查找和筛选不触发册页长动画。

## 5. 动作参数与约束

| 动作 | 原型参数 | 约束 |
| --- | --- | --- |
| 按钮按下 | 缩放 .97，140ms | 仅短反馈，不影响命中区域 |
| 普通页面切换 | 4px / 180ms | 高频键盘操作直接完成 |
| 选册归位 | 440ms，`cubic-bezier(.32,.72,0,1)` | CSS transform 可重新定向，无自动轮播 |
| 选中封面 | 约 −7° 透视；旁侧 ±20° 并缩小 | 不给表格、输入框附加倾斜 |
| 封面打开 | 560ms，从书脊旋开至约 −168° | 唯一偏慢的物件动作；正文可用后不等待装饰完成 |
| 内页翻阅 | 240ms，约 9° 轻翻与淡入 | 取消旧动画；键盘/减少动态直接切换 |
| 合上阅读区 | 160ms，8px 内位移 | Escape 可靠，焦点回到入口 |
| 资料夹 | 280ms，前盖约 −13°、纸张上移 7px | 仅精细指针悬停；触屏不用 hover 模拟打开 |
| 来源侧栏 | 260ms，25px 内位移 | 焦点进入、Escape 关闭，阅读上下文不丢失 |

使用 CSS transition 与原生 Web Animations API 即可。此版不需要 Three.js、Canvas 3D、GSAP、新图标库、网络字体或额外状态框架。正式 React 版可直接使用现有 Ant Design 图标替换原型里的内联 SVG。

同时响应应用动效开关与 `prefers-reduced-motion`。应用到明确的自有组件，**不得再用通配符把所有 Ant Design transition 强改为极短时间**；之前 Modal/Select 的跨 WebView2 可见性经验仍适用。

本轮做了视觉与操作验证，没有测得 WebView2 帧率，不宣称“稳定 60fps”。正式接入后使用真实数据和最低目标机器验收；模糊、阴影过重时先降低表面特效，不降低文字清晰度。

## 6. Luna 实施顺序

1. **全局令牌和壳层**：以现有 liquidLight 为基础修改 ThemeContext、App 和统一样式；保留其他主题、搜索、权限与 AI 行为。不要将本原型当作第二个应用嵌入。
2. **手账完整闭环**：先接同一数据源的册架、阅读、便签和列表，再接现有编辑、证据、轨迹与总结。少量固定形态的 CSS 即可，避免抽象通用 3D 引擎。
3. **首页与项目**：以真实选择器/服务接入各指标与金额来源，沿用现有成本公式、版本、实施/冻结边界。保留表格原有能力。
4. **情报、资料库及其余业务表面**：复用令牌、表格、侧栏与反馈，逐页收口，避免新增大量后置 CSS 覆盖。
5. **桌面回归**：真实 Tauri + WebView2，1400×860、1100×700、125%/150% 缩放、浅深主题、动效开关、键盘、长文本、空数据和大数据量。检查多弹层、焦点恢复和保存失败。

验收截图必须是正式接入后的桌面效果；不能用示例原型截图证明真实业务已经完成。重要变更同步到 AGENTS.md。
