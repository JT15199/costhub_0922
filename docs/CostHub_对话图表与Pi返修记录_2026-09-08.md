## 使用

在支持原生工具的 Pi 对话中，可以直接说：

> 查询项目的模块成本，生成一张对比图，说明数据来源和报价口径。

> 比较附件中的供应商报价，把差异画出来；缺失报价不要当作零。

AI 可调用 `render_analysis_chart`，聊天中出现冷蓝色分析卡片，支持横向柱形、折线与环形图；可以放大、展开数据表、导出 SVG 或打开已保存文件。图表按当前数据快照保存，不会因为数据库后续变化而悄悄改图。来源和口径由 AI 整理，界面明确提醒核对，不将 AI 输入当成已核验事实。

新内置 `analysis-charts` Skill，使用现成 ECharts 生成图，无需 Python、Node、联网或开启终端；没有增加 npm 依赖，也没有复制受许可限制的第三方插件资源。图表合约拒绝非数值、缺失来源、非法构成和超大输入。样例页面使用明确标注的演示数据。

本机命令默认为关闭，当前会话需要时通过“终端”按钮单独授权。此模式拥有当前用户的文件和网络权限，不是沙箱。

## 已修的关键链路

- 两个内置 Skills 随 Rust 编译，在任务 `.skills` 下释放并通过真实加载器读取；普通文件工具不可修改技能资源。
- 继续对话复用原目录，目录与恢复消息一起保存；会话搜索返回恢复数据。
- JSON 保存不再按字符截断。工具前后保存检查点，保存失败停止后续调用；恢复发现结果未知时禁止业务写入，要求先核对数据再新建会话。
- 长工具文本和图片不再被传输层静默丢弃。文件/命令的开始和结束轨迹统一，PowerShell 非零退出报告失败。
- 命令注册后才调度，提前取消不会启动；输出实时回传、边读边存文件，内存预览限制在末尾 12KB，每流输出 32MB 上限。Windows Job Object 负责执行进程树生命周期，超时覆盖进程及输出管道等待。
- 网络提示准确限定为 Ollama 进程隔离；不再用它承诺任意 Shell 外发也受控。
