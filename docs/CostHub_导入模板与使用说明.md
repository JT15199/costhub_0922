# CostHub 导入模板与使用说明

## 模板位置

模板统一放在 `D:\AI coding folder\costhub\templates`：

- `CostHub_器件库导入模板.xlsx`：器件库批量入库
- `CostHub_项目BOM导入模板.xlsx`：当前项目 BOM 批量入库
- `CostHub_SKU变体导入模板.xlsx`：SKU 与基座 BOM 的差异导入
- `CostHub_供应商报价导入模板.xlsx`：招标工作台导入供应商报价
- `CostHub_竞品BOM导入模板.xlsx`：竞品 BOM 与我方物料映射
- `CostHub_用户原声导入模板.xlsx`：用户评价、售后和访谈原声

每个文件都有数据页和“填写说明”页。数据页已冻结首行；报价模板的小计列带公式，可直接向下复制。

## 推荐使用顺序

1. 先在“器件库”导入或维护器件主档。
2. 进入“项目”，选中项目，在 BOM 清单点击“模板”下载项目 BOM 模板，填写后点击“导入”。
3. 在“成本策划”先保存并冻结规格基线，再冻结当前 BOM，之后分解目标成本。
4. 进入“招标工作台”，下载“报价模板”。每家供应商单独保存一份，文件名建议为“供应商名_R2_报价.xlsx”，再点击“导入报价”。
5. 报价导入后在比价矩阵确认“可比/参考/不可比”关系，再生成议价清单。
6. 在“竞品管理”选择竞品，进入竞品 BOM，下载模板后导入；已知我方对应物料时填写“我方名称、我方型号、我方成本”。
7. 在项目的“SKU 变体”页下载 SKU 模板，选择目标 SKU 后导入；系统会预览新增、替换、还原或跳过动作。
8. 在“用户原声分析”顶部选择项目代号，下载模板，至少填写“内容”列后导入；需要本地模型时再点击“开始分析”。

## 成本策划与成本长城怎么用

成本策划按“规格基线 → 标准成本基线 → 参考基线/降本机会 → 变更包 → 目标成本版本”使用：

- **标准成本基线**：先核对当前 BOM 和价格，点击“冻结为成本基线”。它是可追溯的事实口径，后续改 BOM 不会覆盖历史版本。
- **参考基线/降本机会**：把模块当前成本改成有历史报价或供应商依据的合理低位，再点击“确认并进入目标”。机会金额只是可争取空间，不是已实现节省。
- **变更包**：记录“为什么变、从什么变到什么、依据和依赖”。确认变更包只确认记录，不会自动改 BOM；执行后回到 BOM 更新并冻结新版本。
- **目标成本版本**：输入财务允许的整机目标，点击“分解并冻结”。系统按领域分配目标并显示挑战缺口；它是管理版本，不是供应商报价。

**成本长城**用于回答“竞品在哪些维度更强、成本差额由哪些模块支撑”：先选择同档竞品，再点卡片右上角“编辑维度与支撑模块”。维度名称、停用/启用、新增维度和模块映射都只保存到当前项目；配置显示、主控、电源、结构等模块后，表格中的“支撑模块”会展示对应模块。最后按 0–10 分给双方评分；未映射时只显示整机成本差异，不能下钻到模块。

## 字段注意事项

- 金额列只填写数字，例如 `610`，不要带 `¥` 或千分位逗号。
- 项目 BOM 的“项目代号”留空时，会导入当前选中的项目；填写新代号时系统会尝试创建项目。
- 供应商报价的“单价”和“数量”是入库依据，“小计”只用于人工核对，系统会重新计算。
- 同名同型号的器件会优先复用器件主档；建议不要随意改动供应商原始型号。
- 用户原声导入时，顶部选择的产品/项目决定归属；“内容”列是实际分析文本。

## 页面内模板按钮

器件库、项目 BOM、SKU 变体、招标工作台、竞品 BOM、用户原声页面均已提供“模板”或“报价模板”按钮。按钮导出的模板与 `templates` 目录中的文件字段保持一致，适合按当前版本重新下载。
