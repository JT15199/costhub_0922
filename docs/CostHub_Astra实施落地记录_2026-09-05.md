## 已落地

- 安全边界：登录密码不再写入或回显明文；供应商密钥改由 Rust 后端 Windows DPAPI 保管；渲染层只拿元数据和配置状态；云端请求统一由后端校验授权、注入密钥并发出。
- 成本事实：BOM 行统一维护价格/数量状态；缺失、非法、确认零值分离；未知成本不再折算为零；项目快照保存 BOM、规格、费率、SKU 和指纹；冻结历史详情只读冻结事实。
- 成本规划：标准成本按物料、包材、ODM 加工费计算，平台费率单独计算；目标包按完整签名差异向量落位，不按比例摊薄；无完整证据的包不进入机会池；实施包必须关联冻结结果版本和证据。
- 竞价：按供应商、模块、型号、物料键保留原始报价；同键同供应商聚合但可展开原始行；轮次、选择和旧请求切换均有边界。
- 原声与异步：主题重跑保留人工判断；失败运行可见并按完整指纹恢复；项目/请求序列号防止旧结果覆盖新项目；本地模型停止会取消实际流。
- AI 与看板：数字结论携带结构化证据；工具、报告、对比、看板统一使用严格成本；空数据、缺证据、失败和未评分不再伪装成零、完成或趋势。
- 阶段交付：冻结包输出冻结 SKU/差异快照、阶段状态、来源指纹和变更包引用事实；当前数据变化不会漂移已冻结历史。
