AI CAPABILITIES

AI 在成本工作里做了什么

三个 AI 能力，对应成本工作里三件"费时间、靠记忆"的事——每件都先说原来的做法，再说现在的做法：

📈 物料行情洞察

原来查行情开好几个网页，凭印象判断涨跌，说不清依据
现在输入物料名 → 联网搜索 + 框架分析 → 方向 / 置信度 / 幅度 + 真实来源

📝 工作手账 AI 总结

原来交接、复盘时翻记录、凭记忆拼时间线，容易漏
现在平时随手记，AI 按项目拼成"起因 → 过程 → 结果"

💬 本地 AI 助手

原来"上次面板涨价影响了哪些项目？"要自己翻表慢慢对
现在直接问，模型读本地数据回答，可多轮追问

AI 不负责算成本

成本是精确计算，交给工具本身的核算逻辑；AI 负责"找、回忆、归纳"这三件费时间的事——行情判断、历史拼装、数据问答。各干各的，各用所长。

AI BRIDGE

AI 双向洞察 · 本地算、云端查，数据不出门

单条物料想判断行情，但不想把成本数据发出去——三步链路把"读数据"和"查行情"分开：本地模型读你的数据，云端只收到三个字段。

① 本地读数据

本地模型读取建议卡上下文（成本 / 项目都在本机）→ 判断查询意图，只输出 物料名 / 品类 / 问题 三个字段

→

② 云端查行情

固定脱敏模板发送 → 联网搜索行情；发送前自动审计，命中敏感词直接拦截

→

③ 本地给结论

本地模型结合本地成本数据 + 云端行情 → 机会 / 风险 / 目标 / 行动建议，落回建议卡

🔐 安全：不是靠信任，是靠结构

  • 云端提示词是固定模板，只有三个字段位——成本 / 供应商 / 项目代号在结构上无处可传
  • 发送前正则审计兜底：金额 / 型号 / 供应商 / 代号命中即拦截
  • 每次云端调用全程留痕，外发内容随时可审查
  • 每日云端用量阈值可设，超限自动改走本地

♻️ 不重复烧调用

同一物料 7 天内再次洞察 → 先弹出历史结论供复用确认，选"强制最新"才重新查——省调用，也保留判断的连续性

开箱即用：未配置本地模型时自动降级为"规则意图 + 云端结论"

发给外面的每一句话，都经得起检查

本地模型负责"看懂你的数据"，云端模型负责"知道市场行情"——两边各干各的，交接处只有三个字段。

AI LIMITS

AI 的边界 · 它帮不了什么

能做什么讲完了，讲不能做什么——这决定了你该在哪儿用它：

🧠 模型能力有上限

本地 7B 模型擅长总结、对话，复杂分析建议用云端大模型——两条通道各有分工，不是越大越好，是各干各的

📉 置信度常常只有"中"

行情类信息时效短、公开数据有限，AI 说不准时会明说"信号不明确"，不硬给结论——经常要你结合自己的信息再判断

🙈 AI 看不到的

🤝 助手不是专家

方向判断、谈判策略、拍板决策靠人；工具把"查证 + 归纳"这一步做扎实，剩下的还是你的经验

SETUP · 本地模型

配置教程 ①：本地模型（Ollama）

用于本地 AI 对话、工作手账 AI 总结——为什么先配本地？数据不出本机、无需联网、不产生费用。本地模型也能做行情洞察，能力有限，重活建议交给云端（下一页）。

① 安装 Ollama

前往 ollama.com 下载并安装（Windows / macOS / Linux 都支持），安装后托盘区出现 Ollama 图标即成功

② 拉取模型

打开终端执行：
ollama pull qwen2.5:7b
（也可换其他模型，如 llama3.2 / deepseek-r1，尺寸越大越聪明但越吃配置）

③ 验证服务

浏览器访问 http://localhost:11434
看到 Ollama 提示即服务正常（默认端口 11434）

④ 在工具中配置

设置 → AI 服务 → 本地模型区：
地址填 http://localhost:11434，模型选 qwen2.5:7b
（AI 总结可单独指定更快的模型）

💡 提示：本地模型运行需要一定内存（7B 模型约 6-8GB），配置较低的电脑可选用 qwen2.5:3b 等更小的模型；配置完可在"本地 AI 助手"里发一句"你好"测试连通。
SETUP · API KEY

配置教程 ②：外部模型 API Key

用于联网的物料行情洞察（外部大模型 + 搜索）——为什么还要配云端？本地模型能力有上限，行情洞察需要联网搜索，两条通道互补。工具已内置多家供应商预设，三步完成：

① 注册拿 Key

任选一家（点卡片里的官网链接直达）：
DeepSeek platform.deepseek.com
硅基流动 cloud.siliconflow.cn
智谱 GLM open.bigmodel.cn
Kimi platform.moonshot.cn

② 填入工具

设置 → AI 服务 → 添加供应商：
选预设（地址自动填好）→ 粘贴 API Key → 选模型 → 启用
Key 使用 AES-GCM 加密存储，仅本机可解

③ 配置搜索（可选）

行情洞察联网搜索需要搜索服务：
Tavily app.tavily.com
Serper google.serper.dev
填入 API Key 并启用；部分模型支持原生联网搜索（设置里一键开启）

💡 提示：DeepSeek / 硅基流动 / 智谱 GLM 都有免费或低价额度，日常洞察够用；配置完在"物料趋势洞察 → 快捷洞察"里输入一个物料名（如"锂电池"）即可测试全流程。
