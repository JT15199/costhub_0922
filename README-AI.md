# AI智能导入版本使用指南

## 版本说明

**显示器成本管理系统** 现有两个版本：

### 版本对比

| 版本 | 启动命令 | 端口 | 功能 | 适用场景 |
|------|---------|------|------|---------|
| **非AI版本** | `npm run dev` | 5173 | 传统手动导入 | 不需要AI、稳定优先 |
| **AI版本** | `npm run dev:ai` | 5174 | AI智能导入 | 需要AI辅助、格式识别 |

### 核心特性

- ✅ **双版本并行**：两个版本可同时运行，互不影响
- ✅ **数据共享**：共享同一个SQLite数据库
- ✅ **安全隔离**：非AI版本文件100%不变

## 快速开始

### 方式一：非AI版本（默认）

```bash
# 启动传统版本
npm run dev

# 访问 http://localhost:5173
# 使用体验与现在一模一样
```

### 方式二：AI版本（需要安装Ollama）

#### 1. 安装Ollama

**Windows**:
- 访问 https://ollama.ai 下载 Windows 安装包
- 运行安装程序

**Mac**:
```bash
brew install ollama
```

**Linux**:
```bash
curl -fsSL https://ollama.ai/install.sh | sh
```

#### 2. 启动Ollama服务

```bash
ollama serve
```

服务默认运行在 http://localhost:11434

#### 3. 下载AI模型

```bash
# 推荐模型（中文能力强）
ollama pull qwen2.5:7b

# 备选模型
ollama pull qwen2.5:14b  # 更强但稍慢
ollama pull qwen2.5:3b   # 轻量但能力稍弱
```

下载约需10-20分钟（模型约4GB）

#### 4. 启动AI版本

```bash
npm run dev:ai

# 访问 http://localhost:5174/ai.html
# 使用AI智能导入功能
```

**核心功能**：

**可配置项**：
- Ollama服务地址
- AI模型选择

- 高置信度自动应用

### 3. AI缓存管理

**缓存策略**：
- 相同文件自动加载历史识别结果
- 缓存有效期30天
- 可手动清除缓存

## 常见问题

### Q1: 如果没有安装Ollama怎么办？

**A**: 使用非AI版本即可：
```bash
npm run dev  # 传统导入功能完整可用
```

### Q2: AI识别失败怎么办？

**A**: AI失败不影响使用：
- AI版本会提示失败原因
- 可切换到非AI版本继续工作
- 非AI版本传统导入100%可用

### Q3: 如何删除AI版本？

**A**: 直接删除目录：
```bash
rm -rf src-ai
rm ai.html
rm vite.config.ai.ts
# 从package.json删除dev:ai脚本
```

非AI版本继续正常运行。

### Q4: 两个版本数据同步吗？

**A**: 完全同步：
- 共享同一个SQLite数据库（monitor_cost.db）
- AI版本导入的项目，非AI版本能看到
- 非AI版本创建的项目，AI版本也能访问

### Q5: 如何切换模型？

**A**: 在AI设置页面：
1. 启动AI版本 `npm run dev:ai`
2. 点击左侧菜单 "AI设置"
3. 选择模型（下拉菜单）
4. 点击"测试连接"验证
5. 点击"保存配置"

## 技术架构

### AI识别流程

```
用户上传Excel
    ↓
Excel解析（提取样本数据）
    ↓
计算文件哈希
    ↓
检查缓存（相同文件直接加载）
    ↓ 未缓存
AI识别流程：
    ① 结构识别 → 识别模块汇总、明细位置
    ② 列名映射 → 识别字段含义
    ③ 模块推断 → 推断器件归属
    ↓
展示识别结果（置信度可视化）
    ↓
用户确认或调整
    ↓
保存到数据库
```

### 缓存策略

- **文件哈希缓存**：相同文件快速加载
- **相似文件共享**：表头一致的文件共享识别结果
- **30天过期**：自动清理过期缓存
