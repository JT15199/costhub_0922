器件库：价格数据底座
同一器件挂多家供应商报价，加权成本自动计算，任何价格变动有据可查
加权成本 = Σ(启用供应商价格 × 份额比例)
示例：供应商A ¥10 × 60% + 供应商B ¥12 × 40% = ¥10.8

核心能力

  • 多供应商报价管理（名称 / 价格 / 份额 / 状态 / 备注）
  • 最低价自动标绿，价格区间一目了然
  • 改价必填原因，价格历史全程可追溯
  • 成本变动追溯：供应商价格 → 器件成本 → 项目总成本全链路
  • Excel 批量导入导出 · 大类/子类/详细分类三层体系

    📝 记录方式

    • 便签墙：分类章节 + 便签卡片（分类色 / 图钉 / 旋转）
    • 待办清单：进行中 / 已完成分组，勾选即完成

    • 项目标签可自由输入，自动记忆
    • 分类可选：只选项目即可，省去重复选择

    🤖 AI 总结（流式）

    • 时间轴选月份（最早左、最近右，可多选）
    • 两步流程：压缩提炼 → 正式总结（流式呈现）
    • 记录按项目标签分组，AI 不再猜测归属
    • 每个项目串成"起因→动作→结果"故事线
    • 四维度组织：项目 / 公共事务 / 能力建设 / 协作互助
    • 语言书面正式，禁止口语化与编号罗列

    四维度输出示例

    一、项目维度：手写笔：选件→比价→国产化替代→BOM定稿→量产

    供应商管理：器件与 ODM 双轨
    器件供应商按器件报价，整机供应商（ODM）在项目管理中维护、此处自动汇总

    🔧 器件供应商

    • 按器件管理多供应商报价
    • 大类 → 子类筛选联动
    • 供应商地图（按大类分组）
    • 供应商排行榜 / 集中度统计
    • 供应商对比（2-4 家并列）
    • 价格历史与成本追溯

    🏭 整机供应商（ODM）

    • ODM 提供部分或全部物料（含整机 BOM / 结构件 / 组装）
    • 在「项目管理 → 项目详情 → 🏭 整机供应商」中录入报价与份额
    • 此处自动汇总：按供应商分组卡片 + ODM 统计 tab
    • 统计：各项目 ODM 覆盖 + 加权报价 + 承接项目数
    加权报价 = Σ(启用 ODM 报价 × 份额比例)
    示例：富士康 ¥1,295 × 60% + 冠捷 ¥1,318 × 40% = ¥1,304 · 报价变动必填原因，历史可查
