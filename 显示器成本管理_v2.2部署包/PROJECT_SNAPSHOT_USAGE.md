# 项目成本快照功能使用说明

## 📊 **已实现的后端功能（已完成）**

### **核心功能**
- ✅ 保存项目完整BOM快照
- ✅ 快照列表查询
- ✅ 查看单个快照详情
- ✅ 删除快照
- ✅ 快照对比（器件级别差异）

### **数据保存内容**
每个快照保存：
- **版本信息**：版本名称、描述、时间
- **成本数据**：总成本、BOM成本、费率
- **完整BOM**：所有器件的详细数据（名称、型号、成本、数量）
- **分类明细**：各分类成本占比

## 🚀 **如何使用（当前版本）**

### **方法1：通过Dashboard创建**

虽然Dashboard的快照按钮是为全局快照设计的，但你可以：

1. 打开Dashboard
2. 点击"创建快照"按钮
3. 为所有项目创建当前状态快照

**注意**：这会为所有项目创建快照，版本名称为空。

## 💡 **实际使用场景**

### **场景1：版本记录**
```
项目v1.0 → 保存快照（名称：v1.0，描述：初始版本）
→ 成本¥511，BOM器件18件
```

### **场景2：报价前保存**
```
报价前 → 保存快照（名称：报价版，描述：报价前成本）
→ 后续对比报价前后差异
```

### **场景3：降本追踪**
```
实施降本措施前 → 保存快照（名称：优化前）
→ 实施措施后 → 保存快照（名称：优化后）
→ 对比两个快照查看效果
```

---

## 🔧 **快照对比功能**

**对比时会显示**：
- 总成本变化（¥511 → ¥498，-¥13）
- 器件增减：
  - 新增器件（之前没有）
  - 删除器件（之前有，现在没）
  - 成本变化的器件（单价或数量改变）
- 分类成本变化（硬件类¥180→¥175）
